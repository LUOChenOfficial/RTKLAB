# RANSAC后残余风险加权PL：研究原型

当前生产PL仍为原GLS最大包络，不改变主滤波器、整数策略、告警或PL配置。
新增加的`.glsmodes`仅在`enable_rtk_integrity_subset_debug_output`开启时导出；
记录每历元各模式的ENU分离与标准差，不保存或传播子滤波器。

## 模式与概率

模式0：无观测故障且固定正确（浮点输出则为无观测故障）。
模式1/3：单/双观测故障，固定正确；模式2：无观测故障但固定错误。
模式4/5：单/双观测故障与错误固定联合发生。
这些是互斥类别，概率加未建模质量必须为1，不能把相互重叠的事件概率直接相加。
本原型的观测故障模式仅枚举当前参与DD的卫星；RANSAC没有筛选伪距，
因此载波筛选通过概率不能直接作为伪距和整颗卫星故障通过概率。

固定正确的名义模式使用形式固定协方差；模式2使用全观测浮点保护子解。
删星模式目前统一使用浮点子解，分别用于观测故障和联合故障类别。
模式1/3使用浮点协方差是本轮保守代用，并不是“固定正确的子集协方差”。
筛选后的协方差和噪声分布还没有校准，不能声称条件高斯模型已成立。

## 离线求解

每轴试探界L，对各模式构造尾部上界

`T_i(L) = min(1, 2*Phi(-(L-|sep_i|)/sigma_i))`，L≤|sep_i|时取1。

求解`unmodeled_mass + sum(p_i*T_i(L)) <= axis_budget`。
H风险预算平分到E/N，HPL为两轴界的二范数；VPL为U轴界。
不需要假定ENU轴独立，这是矩形包络的union bound。
不利用检测概率进一步降低风险，已有告警或缺失子集的历元保持不可用。
这只是给定条件误差模型下的计算框架；观测分离本身是随机量，
条件概率必须对筛选及检测信息一致定义，不能把此公式当成已证明的完整ARAIM。

`gls_risk.py`要求调用者提供每历元所有模式的概率，不从残差或PE推断。
输入JSON含label、horizontal_budget、vertical_budget、epochs；
epochs按时间键，含probabilities（模式:卫星1:卫星2键）及unmodeled_mass。
如果未建模质量耗尽预算则无有限PL；没有标定信息时不能自动填0。

## 手动敏感性试验

用户授权先手动降低风险寻找PL量级。
`tmp/ransac_gls_20261010/sweep_risk.py`使用真实导出子集进行6×6网格扫描，
扫描p_obs、p_wrong_fix分别为1e-2、1e-4、1e-6、1e-8、1e-10、1e-12。
采用两者独立、单/双观测故障各占一半、类别内子集均匀分配的试探假设。
未建模质量人为设0，另计算两种故障概率均0的名义噪声下限。
这些假设仅用于敏感性分析，不能进入正式完好性结论。
降低概率不能抵消历史共有先验偏差、正常误差模型失配或错误整数风险漏项。

只扫描原监测可用的固定历元；输出全部固定数/可扫描数，并事后统计PE超限。
不得将排除的告警历元、无解历元算作包络成功。PE不参与概率或PL计算。

## 下一步独立标定

1. 记录完整RANSAC候选竞争和最终掩码、噪声模型、环境和几何，而不只记录原始SD值。
   当前RANSAC调试输出中的sd_m不是对获胜模型的拟合后残差。
2. 按完整解算流程进行无故障与单/双/高阶故障注入，包含共同偏差、跨频、伪距、
   时间持续故障及由观测故障诱发的错误固定。用真实几何与可靠基准，另验证整数真值。
3. 标定筛选后残余模式概率、条件误差尾部以及错误固定联合风险；
   使用保守置信上界及不确定性集合，而不是零观测就认定零风险。
   若无法获得独立正确整数基准，不能把Q=1或小PE当作整数真值。
4. 按数据段/环境分离标定与评估，防止相邻历元泄漏；评估覆盖、告警、可用率和计算量。
5. 极小风险不能仅靠几百次注入标定。零事件时95%单侧概率上界约3/N，
   时间相关样本不能简单视为独立；需要明确运行先验、故障幅度/分布模型及尾部论证。

尤其不能把“模拟注入的采样频率”当作运行故障先验。
若在故障H_i下估计选择事件S的概率，Bayes更新需运行先验和所有模式的证据：
`P(H_i|S) = P(S|H_i)*P(H_i) / sum_k(P(S|H_k)*P(H_k))`。
针对连续选择特征应使用概率密度/分箱或显式条件模型，
不能把RANSAC的99%抽样成功设置理解为99%观测无故障概率。
