# IGGIII 迭代试验

默认 `Open_Robust=1`、RANSAC 关闭，`ENABLE_RTK_ROBUST_ITERATION=0` 保留单次降权。将迭代开关设为 1 并重新编译可启用内层权值迭代。数值内核位于 `src/rtk_robust.c`。

固定本历元先验状态、协方差和线性化双差新息。原始观测协方差记为 R0。先由 S0=H'PH+R0 和 Qr0=R0*S0^-1*R0' 得到标准化尺度，所有迭代固定使用 sqrt(diag(Qr0))。这是一项试验性 IRLS 选择；不是把放大后的等效观测噪声作为新的标准化尺度，也不是非线性重线性化。

第 k 轮按当前等效 Rk 计算残差 rk=Rk*(H'PH+Rk)^-1*v。IGGIII 阈值 k0=2、k1=8.5；权因子下限为 1e-6，包含上阈值边界。首轮直接使用目标权值，后续在对数域按 0.5 松弛更新。从 R0 重建等效协方差 Rij=R0ij/sqrt(gamma_i*gamma_j)，不累乘上一轮方差。

最大绝对对数权值变化 <=1e-3 时退出；最多 20 次。达到上限保留最后一轮有效协方差，单独记录为 `maxiter`，不声称收敛。数值失败保持原 R 不变并使当前历元解算失败。外部只执行一次 KF 量测更新，避免重复同化同一观测。

`.rtk_debug` 中 `IGG3_ITER` 记录：时间、观测数、完成迭代数、最大对数权值变化、状态及退出原因（single/converged/maxiter/numerical）。概率解释和完好性保证未由此建立。

`code/tests/robust_test.c` 检查正常观测不改权、上阈值有限性、观测相关系数保持、先验不变、迭代上限及奇异矩阵失败。JC01/JC02/JC04 应按相同配置配对比较单次和迭代版本，统计可用率及共同输出历元上的误差。

2026-10-13 三点完整数据配对试验仅改变迭代开关：单次版本的输出坐标和解状态与试验前结果一致。JC01 指标基本不变；JC02 共同历元 H/V RMS 从 0.4724/0.5358 m 增至 0.4907/0.5459 m；JC04 从 0.1625/0.1747 m 增至 0.1923/0.2008 m，固定率从 53.56% 降至 36.62%。JC02/JC04 分别有 49/11 个历元达到 20 次上限，三点均无数值失败。这仅评估了上述尺度和迭代参数，不是对所有 IGGIII 迭代方案的否定。因此默认不开启迭代。
